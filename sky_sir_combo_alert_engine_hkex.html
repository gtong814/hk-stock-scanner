🧱 核心 Price Action 積木定義 (Pine Script v6)

TrueHigh / TrueLow

納入前一日收市價的真實高低點，避免裂口高開/低開遺漏波幅：max(high, close[1]) / min(low, close[1])

OB (Outside Bar 穿頭破腳)

當日最高價高於昨日最高價，且當日最低價低於昨日最低價：high > high[1] and low < low[1]

Swing S / Swing R

波段支持點 S (low[1] <= low[2] & low) 與波段阻力點 R (high[1] >= high[2] & high)，於當日收市確認前一日高低點。

S陽 / R陰 確認訊號

S陽：陽燭且收市高於前一日高位；R陰：陰燭且收市低於前一日低位。

穿底/穿頂重數 (Reset Mode)

向上組合若低位跌穿 resetLevel、向下組合若高位升穿 resetLevel，系統立即重置步數至 0 並發出提示。

寬鬆模式 (E 與 R 同日)

在 TERE 與 S陽TERE 中，若突破日同時出現 OB、Swing R 或明顯上影線，允許於同日直接由 E 推進至 R 步數。

🚀 GitHub Pages 免費部署指南 (單檔即上線)

本平台為 100% 獨立單檔 index.html，無需後端伺服器或建置工具，3 分鐘即可發佈成公開網站。

  1. STEP 1

    建立 GitHub 儲存庫

    登入 GitHub，點擊右上角 + → New repository，命名如 skysir-hkex-scanner，選擇 Public。

  2. STEP 2

    上傳 index.html

    進入儲存庫，點擊 Add file → Upload files，將本檔案命名為 index.html 拖曳上傳並 Commit。

  3. STEP 3

    啟用 GitHub Pages

    前往 Settings → Pages，於 Branch 選擇 main 與 / (root)，按 Save。

  4. STEP 4

    取得專屬網址 & 鎖定品牌

    透過 https://你的帳號.github.io/skysir-hkex-scanner/ 瀏覽！亦可於「主題與品牌」按「複製客製化預設碼」貼回 DEFAULT_BRAND_CONFIG 永久鎖定全站品牌配色。
